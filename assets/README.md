# Médias personnalisés

Déposez ici vos fichiers, puis modifiez les chemins dans `../js/config.js`.

- `background.jpg` : votre photo de fond (1920 × 1080 recommandé).
- `background.mp4` : votre vidéo de fond en boucle (MP4 H.264 recommandé, sans son).
- `music.mp3` : votre musique de fond (MP3 conseillé).
- `player.jpg` : avatar facultatif du joueur.
- `staff-anna.jpg` : exemple de photo de membre du staff ; utilisez ensuite `image: "assets/staff-anna.jpg"` dans la configuration.

Gardez des fichiers légers : GitHub Pages est idéal pour les images compressées et de courts MP3, pas pour de très lourdes vidéos.
